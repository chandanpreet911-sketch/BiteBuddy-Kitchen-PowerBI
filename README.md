# BiteBuddy-Kitchen-PowerBI
Interactive Power BI Dashboard Project
BiteBuddy Kitchen – Power BI Dashboard

Project Overview

An interactive Power BI dashboard created using a food delivery dataset from Kaggle.

Project Objectives

- Analyze total orders.
- Calculate average delivery time.
- Analyze average delivery rating.
- Compare deliveries across cities.
- Understand delivery performance based on weather and vehicle type.

Tools Used

- Power BI Desktop
- Kaggle Dataset

Dashboard Features

- Interactive slicers for City, Weather Conditions and Type of Vehicle.
- KPI cards.
- Delivery analysis through charts.
- Interactive report filtering.
